# 🚀 Why AK Engine?

Most AI assistants only answer questions.

AK Engine actually performs software engineering tasks.

Instead of asking:

> "How do I build this?"

You simply say:

> "Build this."

AK Engine automatically plans, writes, debugs, runs, and manages projects.

- 🧠 AI Project Planner

# 🤖 Supported AI Providers

- Google Gemini
- OpenRouter
