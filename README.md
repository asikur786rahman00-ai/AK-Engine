# 🚀 What is AK Engine?

AK Engine is an autonomous AI agent framework that can plan, write, debug, execute and manage software projects using multiple AI providers.

Instead of just chatting, AK Engine performs real development tasks.

---

# ✨ Features

- 🧠 AI Planner
- 💻 AI Coding Agent
- 🐞 AI Debugger
- ▶️ Python Runner
- 📁 File Manager
- 🖥 Terminal Agent
- 🧠 Long-Term Memory
- 🌐 Multi-AI Provider Support
- ⚡ Git Agent
- 🔀 Intelligent Task Router
